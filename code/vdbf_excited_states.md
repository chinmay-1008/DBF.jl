# Excited-state energies from vDBF by block decoupling

Idea notes, 13 Nov 2026. Status: nothing implemented or tested yet. Everything below is derivation and plan; items marked **(check)** are assumptions to confirm against the code.

## 1. Goal

Ground-state vDBF rotates $H$ until the reference $|0\dots0\rangle$ is decoupled from everything else. The goal here is to decouple a small **block** of determinants instead, then diagonalise the block exactly. The block eigenvalues are the ground state plus a few excited states.

Two choices of block:

- **Idea 1, HOMO–LUMO block:** the reference plus the determinants reached by flipping only the HOMO/LUMO qubits.
- **Idea 2, Hamming-weight shell:** the reference plus all determinants at Hamming weight 1 (or a chosen part of weight 2).

Both are the same algorithm with a different determinant set $S$.

## 2. Starting point: the current vDBF loop

As confirmed for the current code:

1. Form $G = [H, D]$ with $D = \sum_i Z_i$. $G$ is used **only to rank** candidate Pauli generators.
2. Pick the top-ranked Pauli $P$ (greedy).
3. Rotate $H \to e^{i\theta P/2} H e^{-i\theta P/2}$, with $\theta$ chosen to **minimise $\langle 0|H|0\rangle$**.
4. Truncate, accumulating the discarded energy (measure before and after truncation).
5. Use the energy variance for convergence and extrapolation.

Assumption **(check)**: the Hamiltonian is in a frame where the reference determinant is $|0\dots0\rangle$, so a flipped qubit is a hole (occupied orbital) or a particle (virtual orbital).

## 3. Common framework

### 3.1 What a diagonal $D$ does

The flow generated by $[H, D]$ with diagonal $D$ is gradient descent on $\mathrm{Tr}(HD)$ over unitary rotations of $H$ (Brockett [1], Helmke–Moore [2]).

- Fixed points satisfy $[H, D] = 0$.
- The stable fixed point pairs the largest eigenvalues of $D$ with the lowest eigenvalues of $H$.
- Where $D$ is degenerate, $H$ is left as an undiagonalised block. Choosing the degeneracies of $D$ chooses the block.

Consequence for the current code: $D=\sum_i Z_i$ has eigenvalue $N - 2w$ on Hamming weight $w$, so its exact flow separates all Hamming-weight shells, not just $|0\rangle$.

### 3.2 Block cost for any determinant set $S$

Write $H = \sum_a h_a P_a$. Only Z-strings have diagonal matrix elements, and $\langle x|Z_{\mathbf z}|x\rangle = (-1)^{\mathbf z\cdot x}$. So

$$C_S(H) \equiv \sum_{x\in S}\langle x|H|x\rangle = \sum_{a\,\in\,\text{Z-strings}} h_a\,\chi_a, \qquad \chi_a = \sum_{x\in S} (-1)^{\mathbf z_a\cdot x}.$$

- For $S=\{0\}$, $\chi_a = 1$: the usual "sum of all Z-string coefficients".
- For a block, the cost is the same sum with a per-string integer weight $\chi_a$.
- $C_S$ is linear in $H$.

### 3.3 Angle optimisation is unchanged

Split $H = H_c + H_a$ into parts commuting and anticommuting with $P$. Then (up to the code's sign convention)

$$H(\theta) = H_c + \cos\theta\, H_a + \sin\theta\; iPH_a ,$$

so $C_S(H(\theta)) = a + b\cos\theta + c\sin\theta$ with $b = C_S(H_a)$, $c = C_S(iPH_a)$. The closed-form optimal angle works exactly as for the ground state.

The exact gradient at $\theta=0$ is $c = C_S(iPH_a)$. This gives an exact ranking to cross-check the $[H,D]$ proxy on small systems.

### 3.4 Variational bounds

For an exact unitary transformation:

- $C_S(\bar H) \ge$ the sum of the $|S|$ lowest eigenvalues (Ky Fan [6]; ensemble form in Gross–Oliveira–Kohn [7]).
- Each eigenvalue of the block matrix is an upper bound to the corresponding exact eigenvalue, in order (Cauchy interlacing).

Two caveats:

- The bounds refer to the **whole Fock space** unless symmetries are preserved (see 6.1).
- With truncation the bounds hold only approximately; the accumulated energy correction is the control.

### 3.5 Block variance

The block states are not eigenstates at convergence (only the block is decoupled), so single-state variances do not vanish. The quantity that does:

$$V_S = \sum_{x\in S}\langle x|H^2|x\rangle - \sum_{x,y\in S}\big|\langle x|H|y\rangle\big|^2 = \sum_{x\in S}\big\|(1-\Pi_S)\,H|x\rangle\big\|^2 .$$

- $V_S = 0$ exactly when the block is decoupled.
- For $S=\{0\}$ it reduces to the usual variance.
- Cost: one $H|x\rangle$ per block state, keeping amplitudes that land outside $S$.
- Whether energies extrapolate cleanly in $V_S$ is an open question (section 7).

### 3.6 Final diagonalisation

Build the $|S|\times|S|$ matrix $M_{xy} = \langle x|\bar H|y\rangle$ and diagonalise it.

- Diagonal elements: Z-strings with sign $(-1)^{\mathbf z\cdot x}$.
- Off-diagonal $x\ne y$: only Paulis whose X/Y support is exactly the set of bits where $x$ and $y$ differ, with I/Z elsewhere.
- Phases follow the package's Pauli conventions. Use existing matrix-element routines; do not re-derive phases by hand.

Excitation energies are differences of the eigenvalues of $M$.

## 4. Idea 1: HOMO–LUMO block

Active qubits in the order $(H, \bar H, L, \bar L)$, where the bar is the other spin. "rest" means all other qubits, which stay at 0.

| Variant | Block $S$ (active bits) | Active part of $D$ (added to $\sum_{k\in\text{rest}} Z_k$) | Weight $\chi_a$ for a Z-string |
|---|---|---|---|
| 1a: one spin pair $(i,j)$ | $00,\ 11$ | $Z_iZ_j$ | 2 if II or ZZ on $(i,j)$, else 0 |
| 1b: both spin pairs | $0000,\ 1010,\ 0101,\ 1111$ | $Z_HZ_L + Z_{\bar H}Z_{\bar L}$ | 4 if both pairs even, else 0 |
| 1c: drop the double | $0000,\ 1010,\ 0101$ | $Z_HZ_L + Z_{\bar H}Z_{\bar L} + c\,(Z_H + Z_{\bar H} - Z_HZ_{\bar H})$, $c>0$ | 3 if both pairs even, 1 if one pair odd, −1 if both odd |

"Pair even" means II or ZZ on $(H,L)$, respectively on $(\bar H,\bar L)$.

Notes on the table:

- **1a** is the literal "remove $Z_i, Z_j$, add $Z_iZ_j$". In spin orbitals it holds the reference and one $\alpha\to\alpha$ determinant, which is a singlet/triplet mixture. Good as a first test, not spin-clean.
- **1b** excludes the spin-flip determinants $1001$, $0110$ automatically (they fail one parity).
- **1c**: the bracket $Z_H + Z_{\bar H} - Z_HZ_{\bar H}$ equals $+1$ on the three kept states and $-3$ on $1111$. Over all 16 active states the top eigenspace of $D$ is exactly the three kept states for any $c>0$. Start with $c=1$.
- **1c target states:** S0, S1 and the $S_z=0$ component of T1. If spin symmetry survives, $M$ splits into a 2×2 singlet block and a 1×1 triplet.

How the ranking behaves with the 1c operator:

- A term with X/Y on both $H$ and $L$ commutes with $Z_HZ_L$. It is the in-block $0000\leftrightarrow1010$ coupling and is not proposed by that piece.
- The same term gives $P_aZ_H(1-Z_{\bar H})$ from the $c$ bracket, which acts only when $\bar H$ is flipped. It targets the $0101\leftrightarrow1111$ coupling.
- A term with X/Y on only one of $H, L$ leaves the block and is ranked as usual.
- Greedy single-Pauli picks may also rotate inside the block. The cost is invariant under that.

### Execution, idea 1

Changes to the ground-state loop, in order:

1. **Ranking:** replace $D=\sum_i Z_i$ by the table entry.
2. **Angle:** replace "sum of Z-string coefficients" by the weighted sum $\sum_a h_a\chi_a$.
3. **Energy correction:** accumulate the change in $C_S$ across each truncation.
4. **Convergence:** replace the variance by $V_S$.
5. **End:** build and diagonalise $M$ (2×2, 4×4 or 3×3).

Warm start option: continue from a converged ground-state run (saved generators and angles) and switch to the block cost. This is the sequential scheme of ref. [11].

### When to prefer which variant

- **1c** by default: the HOMO²→LUMO² state usually sits high among many other doubles, and decoupling it is the most intruder-prone part of 1b.
- **1b** when a double-excitation-dominated state lies near or below S1 (stretched bonds, biradicals, polyene-type dark states). Otherwise 1c will try to pull that state into a block built from singles and probably stall.

## 5. Idea 2: Hamming-weight shell

Shell states $|e_i\rangle$ have a single flipped qubit $i$. Shell matrix:

- $M_{ii} = \sum_{a\in\text{Z-strings}} h_a (-1)^{z_{a,i}}$
- $M_{ij}$, $i\neq j$: Paulis with X/Y exactly on $\{i,j\}$, I/Z elsewhere.
- $\langle 0|\bar H|e_i\rangle$: Paulis with X/Y exactly on $\{i\}$. Should be ≈ 0 after ground-state convergence; a useful diagnostic.

Which shell holds which physics **(check against the frame)**:

- Weight 1 = one spin flip ($\Delta S_z = \pm1$) for spin models: spin gap.
- Weight 1 = one electron added or removed under Jordan–Wigner: ionisation potential, electron affinity, charge gap.
- Neutral excitations of a number-conserving $H$ are in weight 2, with one flip on an occupied and one on a virtual orbital ($N_{\rm occ}\times N_{\rm virt}$ determinants).

### Stage 2a: zero-cost baseline (EOM-like)

Take a converged ground-state run, read off $M$, diagonalise. No new flow.

- This is the Pauli-propagation analogue of EOM on a ground-state-decoupled Hamiltonian: q-sc-EOM [10] on the VQE side, EOM-IMSRG [11] in nuclear theory.
- Error source: the shell is still coupled to higher shells. $V_S$ for the shell measures how much.

### Stage 2b: decouple the whole shell

$S = \{0\}\cup\{e_i\}$, $N+1$ states.

- **Ranking:** $D=\sum_i Z_i$ already separates shells. Keep it.
- **Cost weights:** $\chi_a = (N+1) - 2|\mathbf z_a|$, where $|\mathbf z_a|$ is the number of Z's in the string.
- **Risk:** the top of the weight-1 band overlaps in energy with the bottom of higher shells. Those are intruders, and the flow has to sort them.

This is the analogue of the sequential "TDA-IMSRG" scheme in [11], which was reported as more accurate than EOM when it converged and less robust otherwise.

### Stage 2c: only the $m$ lowest shell states

Cost $= E_0 + \sum_{k\le m}\lambda_k(M)$, a state-averaged cost in the spirit of SSVQE [8] and MC-VQE [9].

Per iteration:

1. Diagonalise $M$, keep the lowest $m$ eigenvectors $V_m$.
2. Hold $V_m$ fixed. The surrogate $\langle 0|H(\theta)|0\rangle + \mathrm{Tr}\,(V_m^\dagger M(\theta) V_m)$ is again $a + b\cos\theta + c\sin\theta$.
3. Minimise the surrogate, rotate, re-diagonalise.

Property: by Ky Fan the surrogate is an upper bound on the true cost and equals it at $\theta=0$, so the true cost decreases monotonically.

Extra bookkeeping: shell matrices of $H_a$ and $iPH_a$ for each candidate rotation.

## 6. Risks common to both

### 6.1 Symmetry leakage

Greedy single-Pauli rotations break $N$ and $S_z$ slightly. The Ky Fan target is the lowest states of the whole Fock space, so a block can drift toward low-lying states of the wrong sector. Excitation gaps are small, so this matters more than for the ground state.

- Monitor $N$ and $S_z$ per block state, reusing the diagnostics from the paper appendix.
- Fixes if needed: symmetry penalties, or symmetry-paired rotations.

### 6.2 Intruder states

A state outside the block with energy inside the block's range. The cost resolves it by swapping states, but the flow can become slow or stall at a saddle ($[H,\Pi_S]=0$ with the wrong states in the block).

### 6.3 Delocalised excitations

On translation-invariant lattices the lowest excitation is spread over many sites. A two-orbital block (idea 1) is then a poor starting point; the shell (idea 2) is the natural one. Idea 1 fits molecules with a clear frontier-orbital gap.

### 6.4 Ranking proxy

$[H,D]$ with a few-body $D$ is a proxy for the true gradient of $C_S$. Compare against the exact gradient $C_S(iPH_a)$ on small systems before trusting it at scale.

## 7. Staged plan

All small-system stages: one self-contained notebook each, compared to exact diagonalisation, truncation off first.

| Stage | What | Pass criterion |
|---|---|---|
| 0 | Idea 2a on an 8–12 site Heisenberg chain from a converged ground-state run | Lowest shell eigenvalues vs ED in the matching $S_z$ sector; record the gap to ED and $V_S$ |
| 1 | Idea 1a on a small molecule (minimal basis) or Hubbard cluster, no truncation | $C_S \to E_0 + E_1$ of the sector; $V_S \to 0$; 2×2 eigenvalues match ED |
| 2 | Idea 1c on the same system | Three eigenvalues match S0, T1 ($S_z=0$), S1 from ED; $N$, $S_z$ drift stays small |
| 3 | Idea 2b on the Stage 0 chain | Improvement over Stage 0; note where intruders appear |
| 4 | Turn on coefficient truncation; scan thresholds | Excitation energies stable vs threshold; test extrapolation in $V_S$ |
| 5 | Idea 2c, then larger systems | Only if 3 and 4 look good |

Open questions to answer along the way:

- Do excitation energies extrapolate linearly in $V_S$, as ground-state energies do in the variance?
- How sensitive is 1c to the value of $c$?
- Is block-cost flow from the start better or worse than warm-starting from the ground-state run?
- Do errors cancel in energy differences, or is each block eigenvalue as inaccurate as a ground-state run at the same threshold?
- For neutral excitations in idea 2, is the particle–hole part of weight 2 small enough to handle directly?
- Which system for Stage 1? **Decided (14 Nov):** N2 / STO-3G, frozen core, UNO basis (16 qubits), at R = 1.1 and 2.3 Å, run first with the exact state-vector code (section 7a).

## 7a. Status, 14 Nov 2026: idea 1c with exact DBF on N2

Code: `code/n2_pes/frozen_core/sv_block.jl` (includes `sv_dbf.jl`). No truncation: W is a dense orthogonal matrix on a GF(2) sector, so everything below is the method's own error. Runs: `uno_{1.10,2.30}_block1c_{exact,d1c}`, 200 macro-iterations × 50 rotations, about 2 min each. HOMO = active orbital 4, LUMO = 5 (checked against the Fock diagonal at both geometries).

**Things the plan did not anticipate.**

- *The sector is symmetry-restricted.* `sv_dbf.jl` works in the span of H's x-strings, which only holds determinants with the reference's symmetry. HOMO→LUMO is a different symmetry here, so `sv_block.jl` adds $a, b$ to the span. H is block diagonal across the resulting cosets, the cross-coset block elements stay exactly 0, and the flow decouples $\{|0\rangle\}$ and $\{|a\rangle,|b\rangle\}$ separately.
- *The Ky Fan target is not (S0, S1, T1).* At 1.1 Å the two lowest states of the HOMO→LUMO symmetry are both components of the degenerate ³Πg (297.17 mHa; the π orbitals are not symmetry-adapted, so x and y share a coset), with ¹Πg 50 mHa higher. At 2.3 Å they are ³Σu⁺ (2.84 mHa) and ⁷Σu⁺ (20.14 mHa), the stretched-N2 spin ladder; the HOMO→LUMO singlet is not in the lowest 8.

**Results** (block eigenvalue vs the exact level with the same coset and spin, mHa above FCI):

| R | ranking | S0 | T | 3rd state | $V_S$ |
|---|---|---|---|---|---|
| 1.1 | exact | +0.019 | 297.196 vs 297.174 (+0.022) | ¹Πg 347.421 vs 347.384 (+0.037) | 2.5e-4 |
| 1.1 | d1c | +0.021 | +0.028 | ¹Πg +0.038 | 2.5e-4 |
| 2.3 | exact | +1.56, ⟨S²⟩ 0.76 | 3.684 vs 2.842 (+0.84) | wanders near 120 (⟨S²⟩ 2.06) | 1.7e-3 |
| 2.3 | d1c | +3.33, ⟨S²⟩ 1.37 | +1.74 | drifting toward the septet (⟨S²⟩ 5.9) | 1.6e-2 |

- **1.1 Å works as intended.** The block holds S0, ³Πg and ¹Πg, spin-pure (⟨S²⟩ 0, 2, 0). The Ky Fan minimum would swap ¹Πg for the second ³Πg component, but that rotation has zero gradient by spin symmetry, so the flow stays on this saddle (plan §6.2): C − target plateaus at the 50.2 mHa ¹Πg–³Πg gap, and 1 − F_S at exactly 1/3. Excitation energies: ³Πg 297.177 vs 297.174, ¹Πg 347.402 vs 347.384 (errors partly cancel). Still converging at 200 iterations ($V_S$ falling).
- **2.3 Å does not converge in 200 iterations.** The |0⟩ column picks up the ⁵Σg⁺ state 9 mHa above, the same spin contamination as the ground-state-only flow on bare H (`uno_2.30_onebody`, ⟨S²⟩ 0.32 after 200 iterations). There the fix was $H + 0.05\,S^2$.
- **The d1c proxy ranks as well as the exact gradient** at 1.1 Å (curves nearly identical); at 2.3 Å it is worse.

**Next.**

1. 2.3 Å: add `--s2-penalty` to `sv_block.jl` as in `sv_dbf.jl` and run longer. With exact $[H, S^2] = 0$ the decoupled block of $H + \lambda S^2$ is also decoupled for $H$. The penalty also changes the Ky Fan target in the HOMO→LUMO coset (the septet moves up by $12\lambda$, T1 by $2\lambda$).
2. 1.1 Å: run to convergence, then Stage 4 (port the five swaps to `dbf_groundstate` with truncation at 1e-5 and 1e-6).

## 8. Implementation notes for whoever picks this up

- Code lives in DBF.jl (vDBF) on top of PauliOperators.jl. Touch points: `src/groundstate.jl` (the loop and the truncation calls; there is no `src/truncation.jl`, truncation strategies such as `CoeffTruncation` come from PauliOperators); Hamiltonians and JW mapping in `src/hamiltonians.jl`. The exact state-vector counterpart is `code/n2_pes/frozen_core/sv_block.jl`.
- Use `SparsePauliVector`, not `PauliSum`, for propagation.
- Before writing any helper, check whether the package already has it, and ask before adding new ones.
- Make the minimal change: the five swaps in section 4, nothing adjacent.
- Keep run files small and plain. Notebooks self-contained, with lattice and Hamiltonian written out in the notebook.
- Work on a branch of the personal fork. Do not push to upstream.
- Stage 0 can reuse the replay workflow: load the initial Hamiltonian plus saved generators and angles from `.jld2` and re-evolve.
